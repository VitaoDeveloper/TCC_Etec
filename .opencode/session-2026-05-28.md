## Ação 8 — Hotfix: COUNT SQL com subquery

**Problema:** `products.php:43` usava `strpos($sql, 'FROM')` para extrair a cláusula FROM da query principal, mas o SELECT da query contém uma subquery (`SELECT ... FROM e5_product_images ...`) cujo `FROM` é encontrado primeiro, gerando SQL sintaticamente inválido.

**Solução:** `strpos` → `strrpos` para encontrar o **último** `FROM` (o da query principal).

**Arquivo:** `pages/products/products.php:43`
