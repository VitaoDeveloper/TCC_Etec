## Ação 5 — UI/UX Inconsistências

**Solicitação:** Resolver Seção 7 do `steps.md` (Inconsistências de UI/UX).

### 1. Designs de login unificados
**Problema:** `admin/login.php` e `auth/login.php` tinham layouts completamente diferentes (embedded CSS vs `auth-wrapper` classes).

**Solução:**
- `assets/css/login.css` — reescrito com o layout premium do admin (gradiente escuro, box centralizado com borda arredondada 15px, logo estilizado, inputs com padding 14px, foco dourado)
- `pages/admin/login.php` — removido `<style>` embutido (172→52 linhas), agora carrega `login.css`
- `pages/auth/login.php` — reescrito para usar o mesmo layout `.login-page` / `.login-container` / `.login-box`, mantendo recursos exclusivos (feedback de erro, toggle senha, link de cadastro)
- `assets/css/register.css` — reescrito com o mesmo padrão visual premium
- `pages/auth/register.php` — reescrito com layout `.register-page` / `.register-container` / `.register-box`, botão `btn btn-primary` unificado

### 2. Breadcrumb responsivo
**Problema:** `padding: 120px 0 40px` fixo — mobile com header menor gerava espaço excessivo.

**Solução:** Substituído por `clamp(80px, 10vh, 120px) 0 clamp(30px, 4vh, 40px)` em `style.css:345`.

### 3. Sidebar backdrop
**Problema:** Sidebar mobile do admin abria sem overlay visual para fechar.

**Solução:**
- `admin.css` — adicionado `.admin-sidebar-backdrop` (fixed, inset:0, bg rgba(0,0,0,0.6), z-index:1000, transição de opacidade)
- `script.js` — criado backdrop dinamicamente se não existir; `toggleSidebar()` gerencia ambas classes + `overflow:hidden` no body; clique no backdrop fecha; tecla Escape fecha

### 4. CEP
**Verificado:** Já estava `type="text"` com `pattern="[0-9]{5}-?[0-9]{3}"` e `inputmode="numeric"` — corrigido em sessão anterior. Apenas steps.md atualizado.
